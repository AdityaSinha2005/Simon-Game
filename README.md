# Simon Says Game 🎮

A browser-based memory game inspired by the classic **Simon Says**, developed using **HTML, CSS, and JavaScript**.
The application challenges users to remember and reproduce dynamically generated color sequences, with difficulty increasing at each level.

The project focuses on implementing game logic, state management, DOM interactions, and client-side data persistence.

---

## Key Features

- Dynamic sequence generation using JavaScript
- Progressive level-based gameplay
- Interactive visual feedback with button animations
- High score persistence using Local Storage
- Game over handling and restart mechanism
- Responsive and simple user interface
- Mobile support with tap-to-start interaction
- CSS Grid based responsive layout
- Adaptive sizing using clamp() for improved responsiveness

---

## Tech Stack

**Frontend:** HTML5, CSS3, JavaScript  
**Storage:** Browser Local Storage

---

## Game Flow

1. Start the game using keyboard input or tap interaction
2. Observe the generated color pattern  
3. Repeat the sequence through user interaction  
4. Advance through increasing difficulty levels  
5. Maintain and improve the recorded high score
